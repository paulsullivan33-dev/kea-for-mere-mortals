Refining which UDP operation is refused (python3):

    bind UDP 127.0.0.1:18768: OK
    sendto: [Errno 1] Operation not permitted
    TCP bind+listen on loopback: OK

So UDP sockets can be created and bound, but no UDP packet may be
SENT -- by Kea, by a test client, by anyone in this sandbox. TCP on
loopback works normally, which is why the control agent's REST API
(t06) can be exercised in full while the DHCP packet exchange
cannot. Kea's default raw sockets are refused outright.
