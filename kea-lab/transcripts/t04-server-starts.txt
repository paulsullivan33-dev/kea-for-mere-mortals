  $ kea-dhcp4 -c ../config/kea-dhcp4-lab.conf &

Note what the socket really is: Kea bound a UDP socket on 127.0.0.1:67
because the config says "dhcp-socket-type": "udp". With the default
(raw sockets) startup fails in this sandbox -- t09 shows that failure.
And per t02, no UDP packet can be SENT by anyone here, so the server
can listen but no client exchange can happen. Everything from here
on is done over the control channel, which is how you would also
administer a healthy server on a real network.
