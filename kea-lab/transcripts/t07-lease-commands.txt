Leases, worked through the API (the lease_cmds hook library from the
config is what makes these commands exist). All payloads are the
cmd-lease4-*.json files in kea-lab/config/.

$ POST lease4-get for 127.0.1.120 -- before any lease exists
[ { "result": 3, "text": "Lease not found." } ]
$ POST lease4-add -- 127.0.1.120 to hw-address 02:00:00:00:00:42, hostname lab-laptop, 3600 s
[ { "result": 0, "text": "Lease for address 127.0.1.120, subnet-id 1 added." } ]
$ POST lease4-get for 127.0.1.120 -- now
[ { "arguments": { "cltt": 1793669304, "fqdn-fwd": false, "fqdn-rev": false, "hostname": "lab-laptop", "hw-address": "02:00:00:00:00:42", "ip-address": "127.0.1.120", "state": 0, "subnet-id": 1, "valid-lft": 7200 }, "result": 0, "text": "IPv4 lease found." } ]
